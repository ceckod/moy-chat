## Какво е сайтът (30 секунди)

Чист браузърен (HTML/CSS/JS, без backend) dashboard за пазарен анализ,
писане на текстове, визуализатор и публикуване на музика — CD-B Records.
GitHub Pages hosting. GitHub Actions върши всичко, което изисква cron
(YouTube статистика, trend tracking, niche scoring, auto-update).

**Текуща версия:** виж реда `**Версия:**` в началото на `README.md` —
това е single source of truth за версията, не дублирай числото тук.
